# Zero Control updates

Downloads and the update feed for [Zero Control](https://zero.skillissue.gg/zero-control),
a lightweight remote desktop for Windows, Linux and Android.

Get it from **https://zero.skillissue.gg/zero-control**. Release notes are at
https://zero.skillissue.gg/zero-control/releases.

Installed apps check `zero-control/latest.json` (published from the `gh-pages` branch)
every time they start and update themselves.
