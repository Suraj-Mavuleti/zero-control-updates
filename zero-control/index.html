Zero Control

Windows // Linux // Android // Free // Status: Active

A lightweight remote desktop. Share a 9-digit ID and a password, and control one device from another over the internet, between Windows, Linux and Android in any combination.

Latest version
Also for: Windows Linux Android
Windows: open ZeroControl-Setup.exe from your downloads. It installs for your user only, so no administrator prompt.
Linux: open a terminal and run sh ~/Downloads/zero-control-install.sh. It installs to your home folder and tells you if a system package is missing.
Android: open ZeroControl.apk from the download notification and allow the install. To let another device tap and type on this phone (not just see it), the app offers a small input add-on under "Allow remote control".
Features

Control any screen

See another computer or phone and use its mouse and keyboard as if you were sitting at it.

Private by design

Screen and input go straight between the two devices, encrypted. The password is never sent to any server.

Drag and drop files

Drop files or whole folders onto the session to send them to the other PC.

Light

About 25 MB of memory and no CPU while waiting. Video is encoded and decoded on the GPU.

Unattended access

Set a permanent password to reach your own machines when nobody is there.

Updates itself

Checks for a new version every time it opens and installs it for you.

How it works

Open Zero Control on both devices. The one to be controlled shows an ID and a password; type them into the other one. A small server only introduces the two devices to each other. After that they talk directly, so what is on your screen and what you type never passes through it.

Only give your ID and password to people you trust: whoever has them can see and control your device until you close the app or generate a new password.
